# EdGrim

**EdGrim** بولسا [Grim](https://github.com/GrimAnticheat/Grim) نىڭ فوركى بولۇپ، Grim ئەركىن سىمۇلياتسىيەلىك Minecraft ھىيلە قارشى سىستېمىسىدۇر. بۇ فورك ئەسلى Grim كود ئاساسىغا قوشۇمچە كۆپلىگەن تەكشۈرۈش ۋە بايقاش مودۇللىرىنى قوشىدۇ.

> **ئېلان** — بۇ قۇرۇلۇشتا ئېغىر مىقداردا AI ھاسىل قىلغان كود (Gemini / ChatGPT) بار. ئىشلەپچىقىرىشتا قوللىنىشتىن ئىلگىرى ئەستايىدىلىك بىلەن تەكشۈرۈپ سىناپ بېقىڭ.

## چۈشەندۈرۈش

PacketEvents 2.0 ئارقىلىق 1.21 گە لايىھىلەنگەن، 1.8–1.21 نى قوللايدىغان ئەركىن سىمۇلياتسىيەلىك ھىيلە قارشى سىستېمىسى.

**100+ تەكشۈرۈش**، ئۆز ئىچىگە ئالىدۇ:

| كاتېگورىيە | چۈشەندۈرۈش |
|---|---|
| Aim (نىشانلاش) | ئېۋرىستىكىلىق / ترايېكتورىيە ئاساسلىق نىشانلاش ھىيلە بايقاش |
| Autoclicker (ئاپتوماتىك چېكىش) | چېكىش ئەندىزىسى تەھلىلى |
| BadPackets (ئىناۋەتسىز بوغچىلار) | بۇزۇلغان / ئىناۋەتسىز بوغچىلارنى بايقاش |
| Baritone (بارىتون) | Baritone بوتىنى بايقاش |
| Breaking (بۇزۇش) | بىلەكلەرنى بۇزۇش ئىناۋەتلىكى |
| Chat (پاراڭ) | پاراڭ / بۇيرۇقلارنى سۈيىستېمال قىلىش |
| Combat (جەڭ) | زەربە مۇساپىسى، زەربە قۇتىسى، كۆپ تەرەپلىمە ئىنتېراكسىيە |
| Crash (چۆكۈش) | چۆكۈش ئېكسپلويتىدىن ساقلىنىش |
| Elytra (قانات) | قانات ھەرىكىتى ئىناۋەتلىكى |
| Exploit (ئېكسپلويت) | ئومۇمىي ئېكسپلويت ئازايتىش |
| Flight (ئۇچۇش) | ئۇچۇش / ھەرىكەت ھىيلىلىرى |
| GroundSpoof (يەر ساختىلاش) | NoFall / يەر ساختىلاش |
| Interact (ئىنتېراكسىيە) | ئىنتېراكسىيە ئىناۋەتلىكى |
| Inventory (ئامبار) | ئامبار مەنىپۇلياتسىيەسى |
| Misc (باشقىلار) | خېرىدار ماركىسى، خىيالىي بىلەكلەر، ترانزاكسىيە تەرتىپى |
| Movement (ھەرىكەت) | ھەرىكەت ئەندىزىسى ئىناۋەتلىكى |
| MultiActions (كۆپ ھەرىكەتلەر) | بىرىكمە ھەرىكەتلەرنى سۈيىستېمال قىلىش |
| PacketOrder (بوغچا تەرتىپى) | بوغچا تەرتىپ تەكشۈرۈش |
| PingSpoof (پىڭ ساختىلاش) | پىڭ / كېچىكىش ساختىلاش |
| Prediction (مۆلچەرلەش) | مۆلچەرلەش ئاساسلىق ئوفسېت ۋە فازا تەكشۈرۈش |
| Scaffolding (سېلىش) | سېلىش / مۇنار بايقاش |
| Sprint (يۈگۈرۈش) | يۈگۈرۈش / ھەممە يۆنىلىشتە يۈگۈرۈش |
| Timer (تەيمېر) | ئويۇن تەيمېرى مەنىپۇلياتسىيەسى |
| Vehicle (ماشىنا) | ماشىنا ھەرىكەت ھىيلىلىرى |
| Velocity (سۈرئەت) | سۈرئەت / تەپكە ئىناۋەتلىكى |
